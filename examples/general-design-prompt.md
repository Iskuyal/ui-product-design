# 面向大小模型的通用设计提示词

填入产品事实，在实际项目中执行；已有准确参考或小范围修改时，可省略不相关的探索。完整方法见 [提示词参考](../skills/ui-product-design/references/prompt-recipes.md)。

```text
使用 $ui-product-design，为 [产品] 的 [用户] 完成 [主要任务与可见成果]。
目标平台：[Web / 原生或跨端 App / 微信小程序]。
交付范围：[新设计 / 改版 / 仅设计 / 局部修改]。
必须保留：[品牌、真实行为、数据与权限边界、已有技术栈]。
内容来源：[真实资料或明确标识的演示内容]。

先给精简契约：阅读顺序、内容归属、主动作与结果、必要状态及恢复。
依据本任务选择相关的视觉层级、分组、构图节奏、渐进呈现或错误恢复，落实为具体决定。
自由设计时简短比较不同构图并选定；已有参考时直接深化。
完成范围内全部主要任务，用实际文件/稿件和检查证明结果；记录未验证项。

上下文有限或执行易遗漏时，按契约→方向→实现→验证顺序缩小单次焦点，交接已选决定和不可改变的约束。
继续推进到授权交付完成，不因分阶段就停在规划，不为分数反复重做。
```

关键词是设计词汇与任务提示，不是通用专家激活开关。实际能力以模型、工具、内容和验证结果为准。
